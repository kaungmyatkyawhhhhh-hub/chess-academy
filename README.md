# Rong's Chess Academy

Personal chess training website: 300 puzzle levels, rated puzzles, lessons, opening trainers, famous games and a coordinate trainer.

**Play it:** https://kaungmyatkyawhhhhh-hub.github.io/chess-academy/

- Puzzles: [Lichess puzzle database](https://database.lichess.org/#puzzles) (CC0), every move checked with Stockfish.
- Progress is saved in your browser. Use *Today → Backup and restore progress* to move it between devices.
